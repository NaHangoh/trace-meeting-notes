# 아키텍처

```
[React PWA] ──REST──> [Spring Boot API]
                         ├─ minutes  : 입력 분할(발언 번호), 작업 관리(비동기), 결과 저장
                         ├─ llm      : LlmClient ← Ollama / Claude / Fixture
                         ├─ evidence : 근거 위치 검증(코드), 검증 단계 호출, 판정 합치기
                         └─ export   : docx 생성
                      [DB] 작업·결과 저장
```

## 처리 흐름
1. 스크립트 입력 → 발언 단위 분할, 번호 부여
2. 정리 단계: LLM이 회의록 항목 + 근거 발언 번호를 JSON으로 반환
3. 코드 검증: 발언 번호 존재 여부 확인, 없는 근거 제거
4. 검증 단계: 다른 프롬프트로 항목과 근거 발언 대조 → 판정
5. 검토 화면: 사용자가 항목 수정·삭제·유지 → 확정
6. 내보내기: 확정 내용만 docx로
