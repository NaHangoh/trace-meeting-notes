# 0004. 최종 내보내기에는 확정 내용만
- 날짜: 2026-10-07
- 상태: 확정

## 배경
워드 파일은 회의 참석자에게 공유하는 최종본이다. 근거 연결과 검증 표시는 검토용 작업 정보다.

## 결정
- 검토 화면: 근거 강조, 근거 없음·약함 표시, 항목 수정
- docx: 확정된 회의록 내용만. 발언 번호, 근거, 검증 표시, 도구 메타데이터 없음
- 확인하지 않은 근거 없음 항목이 있으면 다운로드 전에 알린다.
- "근거 부록 포함" 옵션은 1차 범위 밖

## 결과
- 얻는 것: 바로 공유 가능한 깔끔한 파일, 검증 단계가 실제 사용 흐름에 연결됨
- 감수하는 것: 최종 파일만으로는 근거를 다시 볼 수 없음
