# 0003. 정리와 검증을 분리하고, 근거 위치는 코드로 다시 확인
- 날짜: 2026-10-07
- 상태: 확정

## 배경
LLM은 회의에서 나오지 않은 내용을 그럴듯하게 만들어 낼 수 있다. 같은 호출에서 정리와 검증을 함께 하면 스스로 만든 내용을 그대로 통과시킬 가능성이 크다.

## 결정
- 정리 단계와 검증 단계를 다른 프롬프트, 다른 호출로 실행한다.
- LLM이 준 근거 발언 번호는 코드에서 실제 존재 여부를 확인한다.
- 근거 없음 항목은 사용자가 확인하기 전에는 최종본에 넣지 않는다.

## 결과
- 얻는 것: 근거 없는 내용을 걸러낼 구조, eval로 측정 가능한 지표
- 감수하는 것: LLM 호출이 두 배, 처리 시간 증가
