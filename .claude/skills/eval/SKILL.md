---
name: eval
description: eval/cases의 가상 회의로 근거 검증 정확도를 측정하고 결과를 기록한다.
disable-model-invocation: true
---
대상 모델: $ARGUMENTS (예: ollama:exaone3.5:7.8b, claude:sonnet)

1. eval/cases/의 각 케이스(스크립트 + 정답 회의록 + 심어둔 근거 없는 항목 목록)를 읽는다.
2. 대상 모델로 정리와 검증을 실행한다. 실제 API 호출 전에 예상 호출 횟수를 보여주고 사용자 확인을 받는다.
3. 케이스별로 계산한다:
   - 근거 없는 항목 탐지율 (심어둔 항목 중 "근거 없음"으로 잡은 비율)
   - 오탐률 (근거가 있는데 "근거 없음"으로 표시한 비율)
   - 근거 위치 정확도 (연결한 원문 위치가 정답 범위와 겹치는 비율)
4. eval/results/<날짜>_<모델>.md 에 표로 저장하고, 이전 결과와 비교한 요약을 보여준다.
5. 숫자를 보기 좋게 바꾸거나 실패한 케이스를 빼지 않는다.
