# 프론트엔드 규칙 (frontend/)

- React, TypeScript, Vite, Tailwind. 반응형(모바일 먼저)으로 만들고 PWA로 설치 가능하게 한다.
- 검토 화면이 핵심이다: 항목 아래에 근거 발언(번호·화자·내용)을 펼쳐 보여주고, "근거 없음·근거 약함" 항목은 눈에 띄게 표시한다.
- 확인하지 않은 "근거 없음" 항목이 있으면 다운로드 전에 개수를 알리고 확인받는다.
- 서버 상태는 한 가지 방식으로만 관리한다 (예: React Query). 같은 데이터를 여러 곳에 복사하지 않는다.
- 접근성: 버튼과 입력에 라벨, 색만으로 상태를 구분하지 않는다 (아이콘·문구 함께).

## 보안
- LLM 결과와 회의 스크립트는 일반 텍스트로 렌더링한다. `dangerouslySetInnerHTML`을 쓰지 않는다. 마크다운 렌더링이 필요하면 HTML을 허용하지 않는 설정으로 한다.
- `VITE_`로 시작하는 환경 변수는 빌드 결과에 그대로 들어가 누구나 볼 수 있다. 키·토큰을 넣지 않는다. 프론트는 백엔드만 호출한다.
- 작업 ID를 URL에 넣을 때 외부 분석 도구·리퍼러로 새지 않게 한다 (`Referrer-Policy: no-referrer`, 외부 스크립트 없음).
